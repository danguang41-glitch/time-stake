# 时间质押 ⏳

时间是最贵的资产，花出去之前先「质押」——开始前立一个约，结束时结算收获。

它不是普通计时器，而是一本**时间账本**：每一笔时间花出去，都要记下换回了什么。

## 怎么用（苹果手机）

1. 用 Safari 打开本项目的 GitHub Pages 网址。
2. 点底部分享按钮 → **添加到主屏幕**，以后点桌面图标直接打开，像 App 一样全屏使用。

## 核心流程

1. **立约**：选分类（学习 / 阅读 / 运动 / 工作 / 自定义），写一句话目标，设定质押时长（15/25/45/60/90/120 分钟、自定义或不限时），点「开始质押」。
2. **质押中**：全屏大计时器，显示已质押时长、剩余时长和当前目标。支持暂停、提前结算、「被打断 +1」。计时用时间戳差值计算，锁屏、切后台、关掉重进都不会丢计时；未结算的重进会提示继续还是结算。
3. **结算**：显示实际用时、计划时长、履约情况，填写这段时间得到了什么（必填）、是否达成目标、专注度自评（1–5 星）和备注，写入账本。
4. **账本**：按时间倒序，可按分类和日期筛选，点一条可查看详情、编辑收获、删除；支持导出 JSON / CSV。
5. **统计**：今日 / 近 7 天 / 分类占比、连续质押天数、履约率、累计收获，以及🏆收获墙。

## 质押机制

- **履约率**：按计划时长完成结算记为履约，提前结算记为未履约，只统计、不惩罚、不扣分（不限时不计入）。
- **连续天数**：每天至少完成一次结算即延续，断一天归零。
- **收获墙**：所有「得到了什么」汇总成墙，按时间排列，方便回顾。

## 隐私与技术

- 零依赖，纯 HTML / CSS / JavaScript，无需构建。
- 所有数据只存在本机浏览器的 localStorage，不上传任何服务器；换设备前请先在账本页导出备份。
- 支持深色模式，手机优先设计。
